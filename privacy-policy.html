GG Buddy — Privacy Policy

Last updated: June 7, 2026

Overview

GG Buddy is a Chrome extension that helps you compare game prices across stores using the GG.deals API. We are committed to protecting your privacy.

Data Collection

We do not collect, store, or transmit any personal information.

The extension operates entirely locally in your browser. All data remains on your device or, optionally, in your Chrome sync storage (which is managed by Google).

Data Stored Locally

  • Wishlist: Game IDs and titles you choose to track
  • Preferences: Theme, accent color, notification settings
  • Price Cache: Temporary cached price data to reduce API calls
  • Price History: Historical price records for games you've looked up
  • Recent Searches: Your recent search queries

Chrome Sync

If enabled, your wishlist and preferences may be synced across devices using Chrome's built-in sync storage. This is managed by Google's Chrome Sync infrastructure and subject to Google's privacy policy.

How Game-Title Matching Works

To show you prices, GG Buddy has to turn the game you're looking at into a price lookup. Here's exactly what happens, step by step:

  • When a page already has a Steam ID (for example a Steam store page, or a wishlist with known app IDs), GG Buddy uses that numeric ID directly. No game title text leaves your browser.
  • When only a title is known (some non-Steam stores, proxy sites, or when you type a manual search), the detected title text is sent to Steam's public Store Search API (store.steampowered.com/api/storesearch/) to resolve it into a numeric Steam App ID. This request is fixed to l=english&cc=us and contains only the title text — nothing about you.
  • Price lookup. Only the resulting numeric Steam IDs — never the raw title — are then sent to the GG.deals Prices API, along with a shared API key (see below) and your selected region code (e.g. us, uk).
  • Caching. Results are cached locally to reduce repeat requests: price data for about 30 minutes, and title-to-ID lookups in memory for the session. Repeated lookups for the same game may make no network request at all.

All of this happens in real time, only for games you actively view or search. GG Buddy does not pre-scan your browsing or send a list of pages you visit.

Are You Identified or Identifiable?

The extension does not identify you. It sends no account details, no login, no cookies of its own, and no per-user identifier with any request.

  • Shared API key: Requests to GG.deals use a single API key that is the same for every GG Buddy user. It identifies the extension, not you, and cannot be used to single you out.
  • Standard network metadata: As with visiting any website, Steam and GG.deals receive the normal request metadata your browser sends — such as your IP address and user-agent string. GG Buddy adds nothing beyond this and has no servers of its own that receive your data.
  • No tracking or analytics: There is no telemetry, no fingerprinting, and no behavioral tracking anywhere in the extension.

For how Steam and GG.deals handle requests on their side, see their respective privacy policies.

External API Requests

The extension makes requests to the following third-party services:

  • Steam Store Search API — to resolve game titles into Steam App IDs (title text only, as described above).
  • GG.deals API — to fetch game prices, deal scores, and bundle information (numeric Steam IDs and your region preference only).
  • GG.deals website — when you choose to import a public wishlist share link, the extension fetches that share page (and related public game-info snippets) to read game titles and Steam store links. Only the share URL you paste is requested; nothing else from your GG.deals account is accessed.
  • Frankfurter currency API — to convert price thresholds between currencies (currency codes and amounts only).

No personal information, browsing history, or user identifiers are sent with these requests.

Permissions Explained

  • storage: Save your wishlist, preferences, and cache locally
  • activeTab: Detect games on the current store page when you click the extension
  • notifications: Send price drop alerts (optional, user-controlled)
  • alarms: Schedule periodic price checks (optional, user-controlled)
  • contextMenus: Add "Look up on GG.deals" right-click option

Third-Party Services

This extension relies on the GG.deals API and the public Steam Store Search API, and optionally the Frankfurter currency API. Please review GG.deals' Privacy Policy and Steam's Privacy Policy for their data practices.
