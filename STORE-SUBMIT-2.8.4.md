# Store submit — 2.8.4

## Version
2.8.4

## What’s new (short)
Resilience when out of API calls: stale cached prices everywhere, degraded price bar with CTA, quota gate, typed rate-limit errors, auto-retry on reset, stronger free-key nudge.

## Packages
Build with `npm run build-release`, then upload:

- Chrome: `dist-release/ggbuddy-chrome-2.8.4.zip`
- Firefox: `dist-release/ggbuddy-firefox-2.8.4.zip`

## Notes
Public GG.deals Prices API only. No private/extension APIs.
